[TOPOLOGI MEMORI HIPERDIMENSIONAL]

Dalam paradigma Hyperdimensional Computing (HDC), informasi tidak disimpan sebagai skalar
diskrit dalam tabel relasional, melainkan didistribusikan melintasi vektor pseudo-acak
berdimensi sangat tinggi. Topologi ini memanfaatkan fenomena "berkat dimensi" (blessing of
dimensionality), di mana dua vektor acak dalam ruang 10.000-D hampir dipastikan ortogonal.

Topologi ini digerakkan oleh tiga operasi aljabar linear murni untuk membentuk memori asosiatif
dan relasional:

    1. Bundling (Superposisi): Operasi $\mathbf{v}_{bundle} = \mathbf{v}_1 \oplus
         \mathbf{v}_2$. Menggabungkan beberapa hipervektor menjadi satu vektor tunggal yang
         mewakili himpunan vektor asal. Untuk representasi nilai riil, ini adalah penjumlahan
         elemen-demi-elemen yang diikuti dengan normalisasi L2 untuk mencegah pertumbuhan
         magnitudo yang tidak terkendali.

    2. Binding (Asosiasi): Operasi $\mathbf{v}_{bind} = \mathbf{v}_1 \otimes \mathbf{v}_2$.
         Mengikat dua vektor untuk membentuk representasi baru (misalnya, mengikat 'Kunci'
         dengan 'Nilai'). Operasi yang optimal untuk Float32Array adalah Produk Hadamard
         (perkalian elemen-demi-elemen). Vektor hasil akan ortogonal terhadap kedua vektor
         pembentuknya.

    3. Permutasi (Sekuens/Waktu): Operasi $\mathbf{v}_{perm} = \Pi(\mathbf{v})$. Karena
         Bundling bersifat komutatif, urutan waktu membutuhkan operasi non-komutatif.
         Pergeseran sirkular (rotasi matriks 1D) digunakan untuk merepresentasikan jejak
         temporal atau urutan logis dari swarm.

// 1. KELAS VEKTOR HIPERDIMENSIONAL

export class HyperVector {

 public data: Float32Array;

 constructor(initData?: Float32Array) {
   if (initData && initData.length === DIMENSIONS) {
     this.data = new Float32Array(initData);
   } else {
     this.data = new Float32Array(DIMENSIONS);
     // Injeksi entropi pseudo-acak [-1, 1]
     for (let i = 0; i < DIMENSIONS; i++) {
      this.data[i] = (Math.random() * 2) - 1;
     }
   }
 }

 //  Bundling (Superposisi dengan Normalisasi L2)
 public bundle(other: HyperVector): HyperVector {

   const result = new Float32Array(DIMENSIONS);
   let sumSq = 0;
   for (let i = 0; i < DIMENSIONS; i++) {

     result[i] = this.data[i] + other.data[i];
     sumSq += result[i] * result[i];
   }
   const magnitude = Math.sqrt(sumSq);
   for (let i = 0; i < DIMENSIONS; i++) {
     result[i] /= (magnitude || 1);
   }
   return new HyperVector(result);
 }

 //  Binding (Asosiasi Relasional - Hadamard Product)
 public bind(other: HyperVector): HyperVector {

   const result = new Float32Array(DIMENSIONS);
   for (let i = 0; i < DIMENSIONS; i++) {

     result[i] = this.data[i] * other.data[i];
   }
   return new HyperVector(result);
 }

 //  Permutasi (Sekuens Waktu - Circular Shift)
 public permute(shifts: number = 1): HyperVector {

   const result = new Float32Array(DIMENSIONS);
   for (let i = 0; i < DIMENSIONS; i++) {

     result[(i + shifts) % DIMENSIONS] = this.data[i];
   }
   return new HyperVector(result);
 }

 // Hukum Uncomputation Isentropik
 public annihilate(): void {

   for (let i = 0; i < DIMENSIONS; i++) {
     this.data[i] = 0.0;

   }
 }
}

$$W(x,t) = W_0(x) \cdot e^{-\lambda t} + \sum \Delta w_i$$
Parameter Operasional:

     $W_0(x)$: Intensitas feromon awal saat hipervektor pertama kali disuntikkan oleh agen
         perintis.

     $\lambda$ (Lambda): Konstanta peluruhan (Decay Rate). Mengontrol seberapa agresif
         jejak memudar. $\lambda$ yang tinggi berarti informasi sangat volatil dan membutuhkan
         penguatan konstan.

     $\sum \Delta w_i$: Akumulasi penguatan (reinforcement) dari agen lain dalam swarm.
